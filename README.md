# Student Performance Analysis

Bu projede Kaggle’dan alınan Students Performance veri seti kullanılarak öğrencilerin matematik başarıları tahmin edilmiştir.

## Kullanılan Adımlar
- Veri Keşfi ve Ön İşleme
- Görselleştirme (EDA)
- Linear Regression Modeli
- Model Değerlendirme (MSE, R2 Score)

## Kullanılan Teknolojiler
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Sonuçlar
- R2 Score: 0.88
- MSE: 29.09
